# 리믹스 가사 영상 제작기

랩 동아리 리믹스 공연용 가사 영상 도구. `index.html`을 Chrome/Edge에서 더블클릭해서 연다 (서버 필요 없음, 인터넷 연결은 필요 — 폰트와 mp4-muxer를 CDN에서 받는다).

음원 하나를 기준으로 싱크를 찍고 **음원이 들어간 MP4를 바로 출력**하므로, 영상과 음원을 따로 편집할 때 생기는 어긋남이 없다.

## 순서
1. **원곡**과 **Inst**(mp3/wav/m4a)를 열고 커버·곡 정보를 채운다. Inst 없이 원곡만 써도 된다.
   - **싱크**: Inst를 열면 곡 여러 지점을 비교해 앞부분 무음 차이와 속도 차이(파일마다 미세하게 빠르거나 느린 것)까지 자동으로 맞춘다.
     **겹쳐 듣기**를 켜면 두 트랙 전체가 겹쳐 나오는데, 소리가 울리거나 두 번 들리면 어긋난 것이다. −10/−1/+1/+10ms로 맞춘다.
   - 공연 버전 만들기: 재생하면서 들리는 대로 누른다.
     - `2` = 여기부터 Inst만, `1` = 여기부터 원곡만, `3` = 둘 다 (다음 자른 곳까지, 또는 눈금줄에서 드래그로 잡은 구간)
     - `S` = 두 트랙 같이 자르기, `Shift+S` = 선택한 트랙만, `Del` = 지우기(무음), `Shift+Del` = 지우고 뒤를 당기기
     - 파트 순서 바꾸기: 클립 클릭(또는 눈금줄로 구간 잡기) 후 `Alt+←/→` — 원곡과 Inst, 가사가 항상 같이 움직인다. 복제: `Ctrl+D`. 위치: 끌기(가장자리에 자석처럼 붙음), `←/→` 0.01초, 시작 위치 직접 입력
     - `Ctrl+Z` 되돌리기. 트랙별 볼륨 슬라이더. 클립을 옮기면 그 안의 가사 싱크도 같이 옮겨진다.
2. 가사를 붙여넣는다. `@이름` 줄 아래부터 그 멤버 파트이고, `@민준, 서연`은 함께 부르는 파트, `@`만 쓰면 담당자 없음. 빈 줄은 간주(♪).
3. **탭 모드** → `Space`로 다음 줄 시작을 기록(멈춰 있으면 재생), `Backspace`로 마지막 기록을 취소한다. 어려운 구간은 0.75x/0.5x로.
4. 표의 ±0.01/±0.1 버튼이나 파형 마커 드래그로 다듬는다. 전체가 일정하게 늦으면 **전체 오프셋**(기본 -150ms)을 조정한다.
5. **MP4 내보내기**. 영상 H.264 + 오디오 AAC(AAC 인코더가 없는 브라우저에서는 Opus).

프로젝트는 브라우저에 자동 저장된다(음원 제외, 편집 내용은 포함). 다른 PC로 옮길 때는 **저장(JSON)** 파일을 쓰고, 원곡·Inst는 같은 파일을 다시 열면 편집이 그대로 적용된다.

## 싱크 확인 (10초 구간)
1. 파트가 바뀌는 지점 직전으로 이동해 **현재+10초**를 누르고 720p/30fps로 내보낸다.
2. VLC에서 열고 `E` 키(한 프레임씩 진행)로 줄이 바뀌는 프레임을 찾는다. 그 프레임의 시간이 표의 시작 시간에서 구간 시작을 뺀 값과 같아야 한다.
3. 가사 줄과 래퍼 이름표가 바뀌는 순간 소리가 그 줄의 첫 음절과 맞는지 듣는다. 모든 줄이 같은 방향으로 어긋나 있으면 오프셋을 조정하고, 일부 줄만 어긋나 있으면 그 줄만 고친다.
