# STELLIVE ARCHIVE ✦

스텔라이브 멤버별 커버곡 · 오리곡 · 앨범 · 클립 · 팬아트 · 짤을 모아두는 팬 사이트.
GitHub Pages 에서 돌고, 서버 역할은 구글 Apps Script 하나가 한다.

```
index.html          보는 사람용 (홈 · 멤버 · 단체 · 노래 듣기 · 캘린더 · 별표)
admin.html          관리자용 (배너 · 기수 · 멤버 프로필 · 일정 · 올라온 것 지우기)
config.js           ← 칸 세 개만 채우면 된다
data/site.json      멤버 · 기수 · 일정 기본값 (서버 연결 전 미리보기용)
apps-script/Code.gs Apps Script 에 붙여넣을 코드
assets/             로고 · 스타일
js/                 화면 코드
```

## 어떻게 돌아가나

```
사이트 ──읽기──▶ Apps Script ──▶ 공유 구글 드라이브
   │                 │              스텔라이브 아카이브/
   │ 구글 로그인      │                유니/커버곡, 오리곡, 앨범, 클립, 팬아트, 짤
   └──올리기/별표──▶  │                …멤버마다 똑같이
                     │                단체/전체, 1기…4기, 합방/커버곡, 오리곡, 앨범, 클립
                     └──▶ 구글 시트 (링크로 올린 것, 별표)
```

- **파일**은 드라이브 멤버 폴더에 들어간다. 관리자가 드라이브에 직접 파일을 넣어도 10분 안에 사이트에 뜬다.
  파일 이름이 제목이 된다 (`아이돌 (Cover).mp4` → "아이돌 (Cover)").
- **링크**(유튜브 · 치지직 클립 · X · 드라이브)는 시트에 한 줄씩 저장된다.
- **누구나** 구글 로그인하면 올릴 수 있고, 자기가 올린 것은 자기가 지울 수 있다. 관리자는 전부 지울 수 있다.
- **별표**는 로그인하면 구글 계정에, 안 하면 그 브라우저에 저장된다. 로그인하면 둘이 합쳐진다.
- **노래 듣기**: 유튜브는 유튜브 플레이어로, 드라이브 mp4/mp3 는 직접 틀어서 끝나면 다음 곡으로 넘어간다.

`config.js` 를 안 채워도 사이트는 **미리보기 모드**로 돈다 (링크 올리기는 그 브라우저에만 저장).

---

## 1. GitHub Pages 켜기

`Settings → Pages → Source` 를 **Deploy from a branch**, 브랜치 `main`, 폴더 `/ (root)` 로 저장.
1~2분 뒤 `https://hoje-hoje.github.io/stellive/` 에 뜬다.

## 2. 구글 계정 고르기 ⚠️

드라이브와 Apps Script 는 **개인 gmail 계정**으로 만드는 게 좋다.
학교·회사 계정은 "링크가 있는 모든 사용자" 공유가 막혀 있는 경우가 많아서,
그러면 다른 사람이 사이트에서 영상을 못 본다.

## 3. Apps Script 만들기

1. [script.google.com](https://script.google.com) → **새 프로젝트**. 이름은 `스텔라이브 아카이브`.
2. `Code.gs` 내용을 다 지우고 이 리포의 `apps-script/Code.gs` 를 통째로 붙여넣는다.
3. 맨 위 세 칸을 채운다.
   - `CLIENT_ID` : 4번에서 만드는 OAuth 클라이언트 ID (나중에 채워도 된다)
   - `ADMIN_EMAILS` : 관리자 gmail 들
   - `SITE_URL` : 사이트 주소 (끝에 `/`)
4. 위쪽 함수 고르는 칸에서 `setup` 을 고르고 **실행**. 권한 허락 창이 뜨면 허락.
   ("확인되지 않은 앱" 이 나오면 `고급 → 이동`).
   → 내 드라이브에 `스텔라이브 아카이브` 폴더와 멤버별 폴더가 생긴다.
5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**
6. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 `config.js` 의 `scriptUrl` 에 넣는다.

> 코드를 고친 뒤에는 `배포 → 배포 관리 → 연필 → 버전: 새 버전` 으로 다시 배포해야 반영된다.
> (새 배포를 만들면 주소가 바뀐다.)

## 4. 구글 로그인 · API 키 만들기

[console.cloud.google.com](https://console.cloud.google.com) 에서 새 프로젝트를 만든다.

**로그인 (OAuth 클라이언트 ID)**
1. `API 및 서비스 → OAuth 동의 화면` → 외부 → 앱 이름 · 이메일만 넣고 저장. **앱 게시**까지 눌러둔다.
2. `사용자 인증 정보 → 만들기 → OAuth 클라이언트 ID` → 유형 **웹 애플리케이션**
   - 승인된 자바스크립트 원본: `https://hoje-hoje.github.io`
     (집에서 시험하려면 `http://localhost:8000` 도)
3. 나온 클라이언트 ID 를 `config.js` 의 `googleClientId` **와** `Code.gs` 의 `CLIENT_ID` 에 넣는다.
   (Code.gs 를 고쳤으니 3-⑤ 처럼 새 버전으로 다시 배포)

**API 키 (드라이브 영상 자동 넘김용)**
1. `API 및 서비스 → 라이브러리` → **Google Drive API** 사용 설정.
2. `사용자 인증 정보 → 만들기 → API 키`.
3. 키를 눌러서 제한 설정:
   - 애플리케이션 제한: **웹사이트** → `https://hoje-hoje.github.io/*`
   - API 제한: **Google Drive API** 만
4. `config.js` 의 `driveApiKey` 에 넣는다.

키가 없으면 드라이브 영상은 구글 미리보기 창으로 나오고, 끝나도 다음 곡으로 안 넘어간다.
(유튜브 링크는 키 없이도 넘어간다.)

## 5. 관리자 페이지

`https://hoje-hoje.github.io/stellive/admin.html` → 구글 로그인 (ADMIN_EMAILS 계정).

- **사이트**: 첫화면 배너 (X 헤더처럼 가로로 긴 이미지), 제목, 한 줄 소개
- **기수**: 이름 · 색 · 순서
- **멤버**: 프로필 사진, 헤더 이미지, 소개, 생일(`MM-DD`), 데뷔일, 치지직 · X · 유튜브 링크
  저장하면 드라이브에 그 멤버 폴더가 자동으로 생긴다. 이름을 바꾸면 폴더 이름도 따라 바뀐다.
- **일정**: 이벤트 · 방송 · 발매. 생일과 데뷔 기념일은 멤버 정보에서 자동으로 캘린더에 들어간다.
- **올라온 것**: 전부 보고 지우기. 드라이브 파일은 휴지통으로 간다.

이미지는 주소를 붙여넣거나, `올리기` 를 누르면 드라이브 `_사이트/이미지` 에 올라간다.

## 한계

- 사이트에서 파일 올리기는 **35MB** 까지 (Apps Script 한계). 긴 영상은 드라이브 폴더에 직접 넣거나
  드라이브/유튜브 링크로 올리면 된다.
- 치지직 클립과 X 는 그 사이트 창을 그대로 띄워서 보여준다. 노래 듣기 목록에는 안 들어간다.
- 퍼가기가 막힌 유튜브 영상은 자동으로 건너뛴다.
